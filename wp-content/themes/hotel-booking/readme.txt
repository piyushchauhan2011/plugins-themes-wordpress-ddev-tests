A boutique-hotel block theme for learning WordPress theme development.

== Description ==

Hotel Booking is a full-site editing theme with a landing page, room templates, and block patterns for a small hotel site.

Room listings (the `hb_room` post type, room meta, and the `[hotel_room_meta]` shortcode) live in the companion **Hotel Booking Core** plugin. WordPress.org theme review treats that as plugin-territory functionality.

== Installation ==

1. Upload the `hotel-booking` folder to `/wp-content/themes/`.
2. Install and activate the Hotel Booking Core plugin.
3. Activate this theme from Appearance → Themes.
4. Optional: import demo content, then set the Home page as the front page.

== Frequently Asked Questions ==

= Why is there a required plugin? =

Custom post types and shortcodes are not allowed in WordPress.org themes. Hotel Booking Core provides rooms so the theme can stay presentation-only.

= Does the booking form take payments? =

No. It is a GET inquiry form for learning templates and forms.
